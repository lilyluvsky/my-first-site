Quant Moving Average Crossover Backtest

A Python project for testing a simple quantitative trading strategy using historical SPY data.

Project Summary

This project builds a complete basic backtesting workflow: data download, signal generation, transaction-cost adjustment, portfolio simulation, performance metrics, and result visualization.

Strategy Logic

The strategy uses a 20-day moving average and a 50-day moving average. When the short moving average is above the long moving average, the strategy holds SPY. When the short moving average falls below the long moving average, the strategy stays in cash.

Why This Project Matters

The project demonstrates the core structure of a quantitative research pipeline. It avoids live trading and focuses on reproducible historical testing, which is the safer first step for building more advanced trading research systems.
